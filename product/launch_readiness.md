# Product Launch-Readiness Checklist

This checklist is a product-management exercise for a hypothetical pilot; it is not evidence of a real bank launch.

## Product
- [x] MVP problem and target user defined.
- [x] User stories and acceptance criteria documented.
- [x] Feature backlog prioritised.
- [x] Known current-build limitations documented.
- [ ] Primary user research completed.
- [ ] Usability study completed.

## Engineering
- [x] Reproducible synthetic data generation.
- [x] Deterministic recurrence logic implemented.
- [x] Automated tests implemented and passing.
- [x] Interactive product implemented.
- [ ] Production authentication/authorisation.
- [ ] Persistent feedback store.
- [ ] Production monitoring and observability.

## Risk / control
- [x] No real customer data used.
- [x] Application avoids financial-advice claims.
- [ ] Privacy impact assessment for real data.
- [ ] Security review.
- [ ] Regulatory/compliance review.
- [ ] Accessibility review with target users.

## Go/no-go for a controlled user-research pilot
**Go only after** research consent, privacy handling and instrumentation are defined. Current repository is suitable for portfolio demonstration and internal-style product review, not customer deployment.
